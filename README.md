# Comprehension Stack

A conceptual map connecting human sensemaking, evidence, institutional governance and bounded agent execution. Each project can be evaluated and adopted independently.

This repository provides orientation. It does not implement the runtime chain, establish interoperability by itself, or demonstrate field efficacy.

## Project responsibilities

| Project | Responsibility | Boundary |
| --- | --- | --- |
| [Comprehension Scope](https://github.com/cogno-us/comprehension-scope) | Human sensemaking and interpretation guidance | Guidance is not a runtime control or measured behavioral guarantee. |
| [Cognous Evidence Registry](https://github.com/cogno-us/cognous-evidence-registry) | Claim commitments, evidence relationships and lifecycle history | A registered claim is not established truth or permission to act. |
| [Cognous Evidence Attestation](https://github.com/cogno-us/cognous-evidence-attestation) | Issuer-signature verification under explicit trust assumptions | Signature assurance is distinct from factual truth and institutional authority. |
| [Truth–Freedom–Agency Protocol](https://github.com/cogno-us/truth-freedom-agency-protocol) | Guidance for reasoning and human–AI interaction | Instructions alone do not prove enforcement or efficacy. |
| [Cognous Institutional Governance](https://github.com/cogno-us/cognous-institutional-governance) | Alvorada: institutional authority, proportional process, challenge and correction | Repository acceptance does not ratify a constitution or grant authority. |
| [Cognous Execution Runtime](https://github.com/cogno-us/cognous-execution-runtime) | Bounded execution and retained runtime evidence | A reference implementation is not general agent hardening or external settlement assurance. |

The earlier map used the names Clarity Index, BitRep Core and Moltbot Safe. The links above point to the current component repositories rather than reproducing their release status here.

## Where implementation evidence lives

The [Cognous Open Control Stack hub](https://github.com/cogno-us/cognous-open-control-stack) owns the runtime integration map, selected component revisions and release evidence. Start with its [entry guide](https://github.com/cogno-us/cognous-open-control-stack/blob/main/docs/start-here.md), [component lock](https://github.com/cogno-us/cognous-open-control-stack/blob/main/component-lock.json) and [support ledger](https://github.com/cogno-us/cognous-open-control-stack/blob/main/docs/release-status.md).

The hub documents a bounded synthetic reference. C0 retains a check-to-commit race; C1 is optional and same-host; C2/C3 and real external settlement are not established release claims. New component source, a successful test and selection in the hub are separate facts.

See [architecture.md](architecture.md) for the conceptual relationships and [roadmap.md](roadmap.md) for this repository's maintenance scope. Canonical runtime contracts and compatibility decisions remain in the hub and owning components.
